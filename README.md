# Wien → Bratislava Tour-Wetter

Statische, für GitHub Pages geeignete Wetterseite für die Radtour am 24.–25. September 2026. Die Seite lädt Live-Daten und die Stundenprognose direkt von Open-Meteo; ein API-Schlüssel ist nicht nötig.

## Auf GitHub Pages veröffentlichen

1. Neues öffentliches GitHub-Repository anlegen, z. B. `wien-bratislava-wetter`.
2. `index.html`, `styles.css` und `app.js` in den Hauptbranch hochladen.
3. Unter **Settings → Pages** bei **Build and deployment** die Option **Deploy from a branch** wählen.
4. Branch `main` und Ordner `/ (root)` auswählen und speichern.
5. Nach wenigen Minuten ist die Seite unter `https://DEIN-NUTZERNAME.github.io/wien-bratislava-wetter/` erreichbar.

Diese URL kann in Notion mit `/embed` direkt eingebettet werden.
